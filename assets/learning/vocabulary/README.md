# Vocabulary picture rules

These are local, hand-authored SVG learning cards rather than AI-generated images.

Each card must pass this checklist before use:

1. One word maps to one visually unambiguous object or action.
2. The core identifying features are large and obvious at phone size.
3. No decorative feature may make the object resemble a different word.
4. The image has no English text; the word remains a separate learning target.
5. Inspect every SVG at the displayed card size on desktop and mobile.

For animals, use at least three recognition cues. The rabbit, for example, uses two long upright ears, a white oval face, pink inner ears, whiskers, and a small pink nose.
